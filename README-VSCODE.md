# Bloodtasty Inspired Horror Studio

A responsive React + Vite static website inspired by the structure and cinematic horror mood of bloodtasty.com. This is an original implementation: it does not copy the original site's source code or proprietary assets.

## Run in VS Code / Antigravity

1. Install Node.js 18+.
2. Open this folder in VS Code or Antigravity.
3. Open the integrated terminal.
4. Run `pnpm install` (or `npm install`).
5. Run `pnpm dev` (or `npm run dev`).
6. Open the local URL shown by Vite, usually `http://localhost:3000`.

## Routes

- `/` — Home
- `/world-of-bloodtasty` — World / studio philosophy
- `/about` and `/bloodtasty-team-` — About and leadership
- `/terms-and-conditions` — Terms
- `/privacy-policy` — Privacy

## Notes

- Newsletter form is a front-end demo and shows a confirmation state locally; it does not send email.
- Social links point to the public Bloodtasty profiles.
- To add your own hero images, place them in an external CDN or use the WebDev media workflow rather than committing large files to `client/public`.
